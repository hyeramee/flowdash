# flowdash

## 프로젝트 구조 (File Structure)

| 파일         | 용도                                                                                                  |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| `README.md`  | 프로젝트 소개, 팀 구성, 실행법, 회고 등을 적는 문서                                                   |
| `index.html` | 앱의 뼈대. 빈 컨테이너(`#header`, `#controls`, `#board`, `#modal-root`)만 있고, 실제 내용은 JS가 채움 |

### assets/ — 정적 리소스

| 폴더            | 용도                                                              |
| --------------- | ----------------------------------------------------------------- |
| `assets/icons/` | 아이콘 이미지 파일 (삭제/수정 버튼, 우선순위 표시 등에 쓸 이미지) |
| `assets/fonts/` | 웹폰트 파일 (디자인 시안에 특정 폰트 지정 시 여기 넣음)           |

### css/ — 스타일

| 파일                      | 용도                                                                           |
| ------------------------- | ------------------------------------------------------------------------------ |
| `reset.css`               | 브라우저 기본 스타일 초기화 (margin/padding 0으로, 태그별 기본값 통일)         |
| `base.css`                | 공통 변수(색상, 폰트) 정의 + 전체 레이아웃 기본값(#app, #board 그리드 구조 등) |
| `theme.css`               | 라이트/다크 테마별 스타일                                                      |
| `responsive.css`          | 모바일/태블릿/데스크톱 반응형 처리 (메인 레이아웃 차원)                        |
| `components/board.css`    | 칸반 보드(3개 칸) 전용 스타일                                                  |
| `components/card.css`     | Todo 카드 전용 스타일                                                          |
| `components/modal.css`    | Todo 추가/수정 모달창 스타일                                                   |
| `components/controls.css` | 검색·필터·정렬 UI 스타일                                                       |

### js/ — 로직 (루트)

| 파일           | 용도                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| `main.js`      | 진입점. 각 UI 모듈의 init 함수들을 import해서 순서대로 호출만 함 (조립 역할)                           |
| `config.js`    | 고정값 모음 — STATUS(`todo/doing/done`), PRIORITY(`high/mid/low`) 같은 상수                            |
| `storage.js`   | localStorage 저장/불러오기 담당 (`loadTodos`, `saveTodos` 등)                                          |
| `state.js`     | 앱의 현재 상태(todos, filter, theme 등)를 관리하는 핵심 파일. `getState`, `setState`, `subscribe` 제공 |
| `selectors.js` | 자주 쓰는 DOM 선택자를 모아두는 파일                                                                   |

### js/utils/ — 공통 유틸리티

| 파일      | 용도                                                              |
| --------- | ----------------------------------------------------------------- |
| `date.js` | 날짜 관련 계산 함수 (오늘/7일 이내 판단, 날짜 포맷팅)             |
| `dom.js`  | DOM 조작 공통 함수 (요소 생성, 클래스 토글 등 반복되는 작업 모음) |

### js/ui/ — 화면별 로직

| 파일          | 용도                                                           |
| ------------- | -------------------------------------------------------------- |
| `header.js`   | 헤더 영역 — 인사말, 날짜, 닉네임 수정, 테마 토글 버튼          |
| `controls.js` | 검색·기간필터·우선순위필터·정렬 UI와 그 동작                   |
| `board.js`    | 칸반 보드 전체 렌더링 — 3개 칸(할일/진행중/완료)에 카드를 배치 |
| `card.js`     | 카드 하나를 만드는 로직 (제목, 내용, 우선순위, 날짜 표시)      |
| `modal.js`    | Todo 추가/수정 모달창 — 폼 입력, 유효성 검사, 저장             |
| `stats.js`    | 통계 영역 — 전체 개수, 상태별 개수, 달성률 계산/표시           |

---

**전체 흐름:** `index.html`이 뼈대를 잡고, `css/`가 모양을 입히고, `state.js`+`storage.js`가 데이터를 관리하고, `ui/` 안의 파일들이 각 화면 영역을 실제로 그려낸다. `main.js`는 이 `ui/` 파일들의 시작 함수를 순서대로 호출해서 앱을 켠다.
